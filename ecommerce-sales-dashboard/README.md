# E-Commerce Sales Dashboard (Excel)

Interactive Excel dashboard analyzing 51,000+ e-commerce orders to surface
month-wise and region-wise sales performance, with a live filter control for
stakeholders to explore the data themselves.

## Tools
Excel — SUMIFS, pivot tables, dynamic combo-box control, column charts

## Dataset
51,000+ e-commerce orders across 4 product categories and 13 global regions.

## What I did
- Built SUMIFS-driven summary tables to break down sales, profit, and
  quantity by month and by region.
- Designed a dynamic combo-box control linked to 3 column charts, so
  stakeholders can filter the entire dashboard by product category in
  real time, without touching a pivot table or formula.
- Organized the workbook into a clean "Sales Data" sheet (raw data) and a
  "Working Sheet" (dashboard and calculations), keeping the analysis
  separate from the source data.
