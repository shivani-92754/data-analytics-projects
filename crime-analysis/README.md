# Crime Analysis (Tableau)

A 4-dashboard Tableau suite (15 worksheets) analyzing crime data to surface
overall crime patterns, time-based trends, year-over-year rate changes, and
arrest outcomes, with interactive filters for self-serve exploration.

## Tools
Tableau

## What I did
Built 4 linked dashboards, each with its own worksheets:

- **Overall Crime Statistics** — a live crime feed, geo-mapped crime
  locations, and total crime counts.
- **Time Period Analysis** — hourly, weekday, and monthly crime trends to
  identify when incidents are most frequent.
- **Trend Analysis** — year-over-year crime rate changes.
- **Comparative Analysis** — arrest vs. no-arrest outcomes, and domestic
  vs. non-domestic incidents.

Added interactive filters by incident type, location, and year across all
15 worksheets, so viewers can drill into any slice of the data themselves.
